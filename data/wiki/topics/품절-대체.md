# 품절·대체

## 핵심 판단 원칙 (종합 편집자)

- 품절을 늦게 알리면 기다리던 손님 불만이 커진다. 그래서 주문 태블릿과 POS에서 생맥주를 바로 품절로 바꾼다 [C004]
- 소주는 브랜드를 고르는 손님이 많아서 말없이 다른 소주를 내면 바로 알아채고 기분 나빠한다. 그래서 주문받을 때 진로가 없다고 먼저 말한다 [C005]

## 사례 카드

### [C004] 생맥주 케그가 다 떨어졌을 때 병맥주로 안내
- 현장노하우 · 작성 수빈(숙련 8개월) · 갱신 2026-09-15 · 만료 2027-01-13 · 재사용 12회 (도움 11 / 안 됨 0)
- 상황: 금요일 밤에 생맥주 케그가 바닥났고 여분 케그도 없음.
- 판단 이유: 품절을 늦게 알리면 기다리던 손님 불만이 커진다. 병맥주는 양과 가격이 달라서 차이를 먼저 설명해야 손해 본다고 느끼지 않는다.
- 대응:
  1. 주문 태블릿과 POS에서 생맥주를 바로 품절로 바꾼다
  2. '생맥주가 다 떨어져서 죄송해요'라고 먼저 말한다
  3. 카스 병맥주(500ml)를 권하고 가격 차이를 설명한다
  4. 이미 받은 생맥 주문은 병맥주로 바꿀지 손님에게 묻고 POS 메뉴를 바꾼다
- 하면 안 되는 것: 손님에게 묻지 않고 병맥주로 바꿔 내지 않는다.
- 점장 호출 기준: 단체 손님이 생맥 기준으로 예약했거나 가격 차이로 항의할 때
- 재고 품목: 카스 생맥주, 카스 병맥주 ([재고 기준표](../inventory.md))
### [C005] 찾는 소주가 떨어졌을 때 다른 소주 권하기
- 현장노하우 · 작성 민지(숙련 2년차) · 갱신 2026-09-15 · 만료 2027-01-13 · 재사용 9회 (도움 8 / 안 됨 0)
- 상황: 진로를 찾는 손님이 많은데 진로가 다 떨어짐.
- 판단 이유: 소주는 브랜드를 고르는 손님이 많아서 말없이 다른 소주를 내면 바로 알아채고 기분 나빠한다. 도수가 비슷한 것부터 권하면 바꾸는 손님이 많다.
- 대응:
  1. 주문받을 때 진로가 없다고 먼저 말한다
  2. 도수가 비슷한 참이슬 후레쉬를 권한다
  3. 싫다고 하면 다른 주류 메뉴를 보여 준다
  4. 진로 품절을 주방 보드와 POS에 적는다
- 하면 안 되는 것: 다른 소주를 말없이 진로 대신 내지 않는다.
- 점장 호출 기준: 대신 권할 소주까지 모두 품절일 때
- 재고 품목: 진로, 참이슬 후레쉬 ([재고 기준표](../inventory.md))
