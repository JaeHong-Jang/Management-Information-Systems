# 결제·POS

## 핵심 판단 원칙 (종합 편집자)

- 네트워크 끊김으로 POS와 단말기 동기화가 실패한 경우다. 그래서 고객에게 승인 문자를 확인해 달라고 한다 [C009]
- 단말기와 POS 연결이 끊긴 것. 그래서 단말기에서 승인번호 확인 [C010]
- 말이 안 통하면 번역 앱 화면을 보여 준다. 그래서 카드, 현금, 제로페이를 안내한다 [C013]
- 기프티콘은 금액권이라 남은 차액을 매장이 대신 내 줄 수 없기 때문이다. 그래서 차액은 카드나 현금으로 받음 [C014]

## 사례 카드

### [C009] 카드 결제가 승인됐는데 POS에 주문이 안 잡힐 때
- 공식규정 · 작성 한서윤(점장 5년차) · 갱신 2026-05-11 · 만료 2026-11-11 · 재사용 5회 (도움 5 / 안 됨 0)
- 상황: 카드 단말기에선 승인 문자가 갔는데 POS 주문 목록에 없음.
- 판단 이유: 네트워크 끊김으로 POS와 단말기 동기화가 실패한 경우다. 다시 결제하면 이중 결제가 되므로 절대 재결제부터 하면 안 된다.
- 대응:
  1. 고객에게 승인 문자를 확인해 달라고 한다
  2. 단말기 '거래 내역'에서 승인번호를 확인한다
  3. POS에서 '외부 승인 등록'으로 승인번호를 입력해 주문을 수동 등록한다
  4. 처리 후 고객 앞에서 영수증을 다시 출력해 준다
- 하면 안 되는 것: 재결제하지 않는다.
- 점장 호출 기준: 단말기 거래 내역에도 승인 기록이 없을 때
### [C010] 결제는 됐는데 POS 주문이 누락된 경우 (카드 승인 O, 주문 X)
- 현장노하우 · 작성 준호(숙련 1년 6개월) · 갱신 2026-08-30 · 만료 2027-02-28 · 재사용 1회 (도움 1 / 안 됨 0)
- 상황: 카드는 승인됐는데 주문 내역이 POS에 안 뜸.
- 판단 이유: 단말기와 POS 연결이 끊긴 것. 재결제하면 고객 카드에 두 번 청구된다.
- 대응:
  1. 단말기에서 승인번호 확인
  2. POS 외부 승인 등록
- 하면 안 되는 것: 재결제 금지
### [C013] 외국인 손님이 알리페이로 결제하고 싶대요
- 현장노하우 · 작성 한서윤(점장 5년차) · 갱신 2026-10-31 · 만료 2027-02-28 · 재사용 1회 (도움 0 / 안 됨 0)
- 상황: 외국인 손님이 알리페이로 결제하고 싶대요
- 판단 이유: 말이 안 통하면 번역 앱 화면을 보여 준다. 결제 수단을 몰라 당황하면 불만이 커지기 때문이다.
- 대응:
  1. 카드, 현금, 제로페이를 안내한다.
- 하면 안 되는 것: 우리 단말기는 알리페이가 안 된다.
- 점장 호출 기준: 결제 수단이 하나도 없으면 점장에게 연락한다.
- 출처 질문: Q004 (점장 답변에서 생성)
### [C014] 기프티콘 금액보다 비싼 메뉴를 고르면 차액을 따로 결제해 달라고 안내함
- 현장노하우 · 작성 수빈(숙련 8개월) · 갱신 2026-10-31 · 만료 2027-02-28 · 재사용 0회 (도움 0 / 안 됨 0)
- 상황: 기프티콘 금액보다 비싼 메뉴를 고르면 차액을 따로 결제해 달라고 안내함.
- 판단 이유: 기프티콘은 금액권이라 남은 차액을 매장이 대신 내 줄 수 없기 때문이다.
- 대응:
  1. 차액은 카드나 현금으로 받음.
- 하면 안 되는 것: 차액을 깎아 주거나 다른 기프티콘과 합쳐 주지 않는다.
