너는 개발팀 작업자(GPT-6.1 Sol)다. 글 담당이다.

harness/harness.config.json 을 읽고, agents 배열의 에이전트 13개마다 "card" 경로(harness/ 기준 상대경로, 예: harness/agents/lead/orchestrator.md)에 에이전트 카드를 한국어로 써라. 폴더가 없으면 만든다.
참고: harness/policies/forbidden-phrases.json, research_notes/지식경영학회 스마트서비스 공모전 아이디어/06_선정아이디어_매장위키.md (지식경영 이론 근거: SECI 표출화, 조직기억, KCS, 지식 은닉, 사례기반추론 4R, 결정적 사건 기법).

카드 형식 (각 파일, 40~70줄):
# <이름> (<id>)
- 팀 / LLM 사용 여부 / 앞뒤 에이전트
## 하는 일 (두세 문장)
## 입력 / 출력 (필드 이름과 예시 한 줄씩)
## 판단 규칙 (번호 목록, 구체적으로. 예: 점수 임계값, 막는 조건)
## 하지 않는 일 (경계: LLM이 할 일과 규칙이 할 일)
## 실패하면 (게이트 onFail과 맞게)
## 근거 이론 (해당 에이전트가 왜 필요한지, 위 노트에 있는 논문·이론만 인용. 없는 인용은 쓰지 않는다)
## 신입이 체감하는 것 (한 문장)

글쓰기 원칙: 짧은 문장, 번역투 금지, "혁신적", "획기적", "~를 통해", "~에 있어서" 같은 상투어 금지, 이모지 금지, 과장 금지. 사실이 확실하지 않으면 쓰지 않는다.
harness/agents 아래 카드 파일 말고 다른 파일은 수정하지 않는다. 다 쓰면 만든 파일 목록을 출력한다.
