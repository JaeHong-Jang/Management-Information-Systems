# 원인 분석가 · cause-analyst

저평점 리뷰에서 같은 불만이 어느 원인에 해당하는지 설명한다.

## 입력과 출력

- 입력 — 해당 매장의 Review, ComplaintType, HqStandard.
- 출력 — Finding[], 이를 묶는 Diagnosis.

## 판단 규칙

기본 원인과 예외표를 적용한다. 같은 리뷰의 규칙 불만을 동반한 직원 태도는 지식 공백으로 본다. 다른 지점 비교는 판단에서 제외한다.

## 근거 규칙

각 판단에 해당 매장의 reviewId와 일치하는 원문 구절을 붙인다.

## 하지 않는 것

손님의 경험에서 점주의 의도나 직원 신원을 추정하지 않는다.

## 실패 시 동작

LLM 실패 시 규칙 분류와 원문을 사용한다. 인용이 남지 않는 판단은 보류한다.

## 관련 흐름

diagnose → 표준 차이 탐지원. (출처: docs/PLAN.md §3~6, shared/contracts.ts)
