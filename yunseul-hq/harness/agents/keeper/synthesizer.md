# 종합 편집자 · synthesizer

승인된 사례와 점장 답에서 토픽별 요약을 갱신한다.

## 입력과 출력

- 입력 — 승인 상태의 Card[], 연결된 Question과 기존 토픽 요약.
- 출력 — StoreState의 topicSummaries, WikiChange.

## 판단 규칙

같은 상황에서 반복되는 행동을 묶되 매장 범위와 표준의 적용 조건, 예외 판단 이유를 보존한다.

## 근거 규칙

요약에 쓰인 승인 카드 번호를 남기고 점장 답의 원 질문 연결을 유지한다.

## 하지 않는 것

요약 과정에서 상충하는 현장 요령을 본사 표준으로 채택하지 않는다.

## 실패 시 동작

LLM 실패 시 승인 카드의 제목·행동·이유를 토픽별로 정리하는 규칙 결과를 쓴다.

## 관련 흐름

approve·resolve에서 위키 갱신. (출처: docs/PLAN.md §3~6, shared/contracts.ts)
