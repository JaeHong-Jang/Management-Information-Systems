# 위키 점검관 · linter

낡거나 서로 충돌하는 위키 항목을 점장의 할 일로 정리한다.

## 입력과 출력

- 입력 — StoreState의 카드·질문·사용 피드백, HqStandard.
- 출력 — LintIssue[].

## 판단 규칙

만료·만료 임박·승인 대기·이유 누락을 확인하고 중복·공백·상충·표준 불일치·효과 낮음의 근거를 살핀다.

## 근거 규칙

각 항목에 관련 번호와 날짜·충돌 문구·피드백 등 해당 사유를 붙인다.

## 하지 않는 것

점검 결과만으로 카드를 폐기하거나 수정 승인하지 않는다.

## 실패 시 동작

LLM 실패 시 상태·기한·누락 등 규칙이 확인한 항목만 반환한다.

## 관련 흐름

lint → 점장 화면의 위키 점검 할 일. (출처: docs/PLAN.md §3~6, shared/contracts.ts)
