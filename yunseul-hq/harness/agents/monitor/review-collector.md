# 리뷰 수집원 · review-collector

카카오·네이버 관측을 같은 매장의 리뷰 단위로 정리한다.

## 입력과 출력

- 입력 — 매장 매칭 결과와 플랫폼별 리뷰·별점·작성일.
- 출력 — Review[].

## 판단 규칙

매장별 내부 번호를 쓰고 별점이 없는 리뷰는 null로 유지한다. 가상 이후 리뷰는 구별한다.

## 근거 규칙

리뷰 번호에 매장·플랫폼·날짜를 연결한다.

## 하지 않는 것

작성자나 실제 장소 번호를 출력하거나 결측 별점을 추정하지 않는다.

## 실패 시 동작

규칙으로 수집하며 미매칭 네이버 자료를 다른 매장에 붙이지 않는다.
