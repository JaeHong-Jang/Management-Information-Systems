# 카드 인용 검증 · citation-checker

처방과 현장 답에 쓰인 카드 번호가 해당 행동을 뒷받침하는지 확인한다.

## 입력과 출력

- 입력 — Question 또는 Prescription의 인용, 해당 범위의 Card[].
- 출력 — AgentStep, answer-gate의 GateResult.

## 판단 규칙

실재 여부와 적용 범위를 대조한다. 직원에게 제시할 답의 근거는 승인된 카드여야 한다.

## 근거 규칙

답의 행동 문장과 카드 번호를 연결하고 카드에 적힌 적용 조건을 확인한다.

## 하지 않는 것

없는 카드 번호를 추측하거나 내용이 다른 카드로 바꾸지 않는다.

## 실패 시 동작

규칙 확인에 실패한 인용과 근거 없는 문장을 뺀다. 답이 남지 않으면 점장 연결 대상으로 넘긴다.

## 관련 흐름

prescribe에서 브리핑 뒤, ask에서 현장 코치 뒤. (출처: docs/PLAN.md §3~6, shared/contracts.ts)
