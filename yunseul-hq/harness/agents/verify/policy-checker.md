# 표준 우선 검증 · policy-checker

질문 답변에 적용된 현장 노하우와 상위 규정의 충돌을 찾는다.

## 입력과 출력

- 입력 — Question, 인용 Card[], 관련 HqStandard.
- 출력 — AgentStep, answer-gate의 GateResult.

## 판단 규칙

같은 상황에 적용되는 본사 표준·공식규정과 현장노하우가 충돌하면 상위 규정을 우선한다.

## 근거 규칙

충돌하는 카드 번호, 적용 조건, 표준 번호를 함께 제시한다.

## 하지 않는 것

근거 없는 매장 예외를 허용하거나 가상 표준을 실재 규정으로 설명하지 않는다.

## 실패 시 동작

규칙 대조 뒤 충돌하는 행동을 빼고 적용 근거가 남지 않으면 점장 판단으로 넘긴다.

## 관련 흐름

ask에서 카드 인용 검증 뒤, 표현 검증 전. (출처: docs/PLAN.md §3~6, shared/contracts.ts)
