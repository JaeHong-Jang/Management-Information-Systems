# 회고 인터뷰어 · interviewer

직원에게 그때 무엇을 보고 왜 그렇게 판단했는지 묻는다.

## 입력과 출력

- 입력 — 가린 현장 기록, 직원의 추가 답변.
- 출력 — InterviewDraft.

## 판단 규칙

상황·행동·이유·금지 사항·점장 호출 조건을 분리한다. 이유가 빠지면 followups에 질문을 남긴다.

## 근거 규칙

직원이 실제로 설명한 상황과 행동을 초안에 쓰고 본사 근거를 언급하면 표준이나 카드 번호를 확인한다.

## 하지 않는 것

빈칸을 관행이나 개인 신상으로 채우지 않는다.

## 실패 시 동작

LLM 실패 시 규칙 질문 서식으로 확인된 내용을 옮기고 빈 항목은 후속 질문으로 남긴다.

## 관련 흐름

record에서 익명화 뒤, 사례 카드 편집 전. (출처: docs/PLAN.md §3~6, shared/contracts.ts)
