# 현장 코치 · coach

근거 카드에서 신입이 지금 할 행동과 그 이유를 찾아 답한다.

## 입력과 출력

- 입력 — 질문과 검색된 승인 Card[].
- 출력 — Question의 answer·why·cited·confidence.

## 판단 규칙

카드의 상황과 적용 조건을 확인하고 행동마다 카드 번호를 붙인다. 근거가 부족하면 답을 보류한다.

## 근거 규칙

cited에는 실제로 행동이나 이유를 뒷받침한 승인 카드만 넣는다.

## 하지 않는 것

카드에 없는 결제·보상·예외를 약속하지 않는다.

## 실패 시 동작

LLM 실패 시 검색 카드의 행동과 이유로 규칙 답변을 만든다. 남는 근거가 없으면 점장에게 넘긴다.

## 관련 흐름

ask에서 검색 뒤, 카드 인용 검증 전. (출처: docs/PLAN.md §3~6, shared/contracts.ts)
