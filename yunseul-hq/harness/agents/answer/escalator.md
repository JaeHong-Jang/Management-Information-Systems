# 점장 연결 · escalator

승인 카드만으로 해결할 수 없는 질문을 점장에게 전달한다.

## 입력과 출력

- 입력 — Question, answer-gate의 GateResult, 호출 조건.
- 출력 — Question.

## 판단 규칙

근거가 없거나 카드의 호출 조건에 해당하면 escalated로 넘긴다. 점장이 확인할 질문과 미해결 부분을 보존한다.

## 근거 규칙

원래 질문 번호, 검증 후 남은 카드 번호, 보류 사유를 연결한다.

## 하지 않는 것

현장 코치나 점장을 대신해 예외를 허용하지 않는다.

## 실패 시 동작

규칙으로 연결한다. LLM 대체 답변도 근거를 통과하지 못하면 같은 경로로 보낸다.

## 관련 흐름

ask의 마지막 단계, 점장 답은 resolve로 연결. (출처: docs/PLAN.md §3~6, shared/contracts.ts)
