# 검색 사서 · librarian

질문에 적용할 근거 카드를 찾는다.

## 입력과 출력

- 입력 — Question의 매장·질문 본문, StoreState의 cards.
- 출력 — AskResult의 candidates, 근거 후보 Card[].

## 판단 규칙

승인된 브랜드 공통 카드와 해당 매장 카드 안에서 상황·토픽·표현이 맞는 후보를 찾는다.

## 근거 규칙

후보마다 실제 카드 번호·제목·검색 점수를 보존한다.

## 하지 않는 것

다른 매장의 로컬 카드나 승인 대기 카드를 답변 근거로 넘기지 않는다.

## 실패 시 동작

규칙 검색에서 후보가 없으면 빈 목록을 넘겨 점장 연결이 가능하게 한다.
