# 윤슬 HQ 작업 규칙

역전할머니맥주 본사용 가맹점 서비스 편차 진단·처방 대시보드. 기술 원본은 `docs/PLAN.md`, 타입 원본은 `shared/contracts.ts`다. 둘과 다르게 만들려면 원본부터 고친다.

1. 브랜드는 실명, 매장은 익명이다. 타깃 매장은 '강남 윤슬점'. 화면·시드·문서에 실제 매장명, 실제 주소, 카카오·네이버 place id, 리뷰 작성자 정보를 넣지 않는다. 실명 원자료는 `data/source/`에만 있고 커밋하지 않는다.
2. 본사 표준과 처방 이후 리뷰는 가상이다. 화면에 '가상' 표지를 붙인다.
3. 숫자(점수·순위·비율)는 규칙 코드가 계산한다. LLM은 분류·설명·초안만 쓰고, 모든 주장에 리뷰 인용이나 카드 번호를 붙인다. LLM이 없거나 실패하면 규칙 결과로 같은 모양을 낸다.
4. 코드는 Claude 쪽이 쓰고, 사람이 읽는 기획·설명 글은 GPT 쪽이 먼저 쓴다.
5. 포트: 백엔드 8788, 프론트 5176.
6. 화면 문안은 명사형으로 끝나는 개조식(논문어체), 이모지 없음. 고객 응대 예문·리뷰 인용·작성자가 남긴 기록은 원문 유지. 빨강은 '고위험'에만 쓴다.
