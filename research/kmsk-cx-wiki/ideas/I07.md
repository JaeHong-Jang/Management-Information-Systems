# I07 · 내가 정하는 개인화 기억

고객이 기억 범위와 삭제를 정하는 서비스 카드

[위키 홈](../README.md) · [후보 비교](ideas.md) · [검증 계획](../validation.md)

## 고객과 해결할 문제

개인화는 원하지만 회사가 무엇을 기억하는지 모르는 고객.

## 만들고 싶은 고객 경험

이번 문의만 쓸 정보와 다음에도 기억할 선호를 직접 정한다.

## 고객 여정

정보 제안 → 목적별 공유 선택 → 개인화 적용 → 기억 목록 확인·수정 → 삭제 상태 확인.

## 지식경영 기여

민감한 원문을 모으는 대신 필요한 선호만 분리하고 사용 근거를 보여준다.

## 기존 서비스와의 차이 — 검증 전 가설

개인화·동의 관리와 유사하다. 통제감 상승이 실제 사용 부담을 상쇄하는지 검증해야 한다.

## 학생 팀의 최소 구현

가상의 쇼핑 추천에서 사이즈·예산·색상 선호만 사용하고 실명 데이터는 받지 않는다.

## 검증 실험과 지표

일괄 기억 / 항목별 선택 / 문의 후 만료 조건을 비교해 통제감·입력 부담·추천 유용성을 측정.

측정 지표: 선택 이해도, 정보 제공 의향, 삭제 성공, 추천 유용성, 설정 시간.

## 고객과 사업성 가설

고객지원·커머스 솔루션의 기능으로 제안. 독립 서비스의 구매자는 불명확.

## 취약점·중단 조건

복잡한 설정으로 피로가 늘 수 있다. 삭제가 검색 인덱스와 파생 기록에도 반영되는지 확인. 기존 방식보다 핵심 성과가 좋아지지 않거나 추가 운영 부담이 편익을 넘으면 범위를 줄이거나 다른 후보를 선택한다.
