# 판정관 (judge)

- 팀: 검증팀 (verify)
- LLM 사용: 아니오. 규칙만 쓴다.
- 앞뒤 에이전트: judge: orchestrator → 본인 → 흐름 종료

## 하는 일

근무 단계의 판정표를 줄마다 합격 · 불합격 · 모름과 근거로 채점한다. 일한 사람이나 일한 AI는 채점하지 않는다.

## 판단 규칙

1. 자료로 확인(auto): 저장된 자료를 직접 본다. 예: 오늘 마감 실사가 있는가, 보내지 않은 주문서가 있는가, 승인 대기 보정이 있는가.
2. 직접 체크(self): 체크가 있으면 합격, 비어 있으면 모름. 비어 있으면 합격이 아니다.
3. 점장이 볼 것(look): 점장이 확인해야 합격. 취향·현장 판단처럼 AI가 정할 수 없는 줄이다.
4. 모든 줄이 합격이면 단계 합격 → 다음 단계. 불합격이 있으면 이유를 붙여 되돌린다. 3번 불합격이면 점장에게 넘긴다.
5. 같은 줄이 근무 두 번 이상에서 불합격하면 위키 점검관이 '반복 실수'로 점장 할 일에 올린다.

## 근거

「지속 가능한 구조」 0단계(판정표 칸 3개: 됨의 뜻·출처·사람이 볼 것, 다른 대화가 채점, 비어 있으면 모름, 3번 불합격이면 사람에게).
