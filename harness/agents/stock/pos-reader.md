# POS 정리원 (pos-reader)

- 팀: 재고팀 (stock)
- LLM 사용: 아니오. 규칙만 쓴다.
- 앞뒤 에이전트: pos: orchestrator → 본인 → 레시피 편집자

## 하는 일

POS에서 내려받은 매출 CSV를 날짜·메뉴·수량으로 정리하고, 소모량표에 없는 메뉴를 찾는다.

## 입력 / 출력

- 입력 `file`, `bytes`: 파일 이름과 원본. UTF-8이 아니면 EUC-KR로 읽는다.
- 출력 `sales`: 날짜·메뉴별 합계. 예: `{date: "2026-10-30", menu: "소맥 세트", qty: 14}`.
- 출력 `unknownMenus`: 소모량표에 없는 메뉴. 예: `["진저 하이볼"]`.

## 판단 규칙

1. 열 이름은 일자·판매일자·영업일자, 메뉴명·상품명·품목명, 수량·판매수량을 같은 뜻으로 본다.
2. 날짜는 2026-10-30, 2026.10.30, 20261030, 2026/10/30을 받는다.
3. 음수 수량(취소·반품)은 그날 합계에서 뺀다.
4. 같은 날짜가 다시 올라오면 그 날짜의 판매를 새 파일로 바꾼다(두 번 올려도 두 배가 되지 않는다).

## 하지 않는 일

메뉴 이름을 추측해서 합치지 않는다. 날짜·수량을 못 읽은 줄은 건너뛰고 개수를 남긴다.
