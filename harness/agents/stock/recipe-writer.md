# 레시피 편집자 (recipe-writer)

- 팀: 재고팀 (stock)
- LLM 사용: 예. 호출 실패나 키 없음 시 규칙 모드로 대체한다.
- 앞뒤 에이전트: pos: POS 정리원 → 본인 → 수요 분석가

## 하는 일

처음 보는 메뉴가 재고 품목을 얼마나 쓰는지 초안을 만든다. 예: 소맥 세트 1 = 참이슬 1병 + 카스 병 2병.

## 입력 / 출력

- 입력 `menus`: 처음 보는 메뉴 이름. 입력 `items`: 품목과 단위.
- 출력 `recipes`: `{menu, lines: [{itemId, qty}], status: "pending"}`.

## 판단 규칙

1. 초안은 모두 승인 대기다. 점장이 승인하기 전에는 사용량 계산에 넣지 않는다.
2. 규칙 모드: 이름이 겹치는 기존 메뉴가 있으면 그 소모량을 복사한다(진저 하이볼 ← 하이볼). 메뉴 이름이 품목 이름과 같으면 1개로 둔다. 둘 다 아니면 빈 초안으로 둔다.
3. 없는 품목 번호나 0 이하·10 초과 소모량은 버린다.

## 하지 않는 일

매장이 정하지 않은 레시피를 확정하지 않는다.
