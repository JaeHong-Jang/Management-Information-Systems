# 수상작 공통 패턴 7가지와 발표 체크리스트 (pattern-winners-common)

> 관련: [[kmsk-society-judges]] · [[kmsk-contest-hub]] · 전체본 docs/references/winners.md. 확인하지 못한 항목은 [미검증]으로 표시. 평가항목 약칭: [문제][AI][창의][비즈][기술] 각 20점.

## 5. 수상작 공통 패턴 7가지

1. 문제 대상이 구체적이다. 건강한기대(개인 식단), 대나무숲(정신질환 위험군), 고찌봄(고령자 복약), 트리아제(응급환자), Konveyor(신입 엔지니어 온보딩). 우리는 "알바 교체 때마다 달라지는 응대"를 신입 알바, 점장, 고객 3주체로 쪼갠다.
2. 데이터 출처를 실명으로 쓴다. LinkedIn·GitHub·Notion, 스마트워치 센서, 국민여행조사, TourAPI, 공공데이터 + MCP. 우리는 POS 로그, 쿠폰 오류 코드, 고참 인터뷰 음성/메모를 실명 데이터로 적는다(합성 데이터는 합성이라고 밝힌다).
3. 사회·경영 지표와 연결한다. 자살률 감소, 체류 및 소비 증진, 온보딩 시간. 단, Konveyor와 WorkWizee처럼 근거 없는 퍼센트는 페이지가 스스로 "미검증"으로 표시했다. 우리는 출처 있는 문제 통계와 "목표 가정"을 분리 표기한다.
4. 실현 가능성이 말로 평가된다. NIA 김성현 "구현 가능성이 매우 높은", 서비스경영학회 "시장성·실현 가능성·확장성", 세종대 호텔 "당장 현업에 적용해도". 기술 구성도 한 장, 1개 매장 파일럿 후 확장 경로 한 장을 둔다.
5. 돌아가는 데모가 있다. ODSC "60-second live demo", Konveyor Loom 영상, 해커톤 바이브 코딩 시연, Bit2Brain 지식 지도. 시연할 최소 구현물과 녹화 백업을 준비한다.
6. 에이전트는 역할을 쪼개고, 한계 밖은 사람에게 넘긴다. konveyN2AI 3-에이전트(검색/역할 프롬프트/오케스트레이션), Apollo 하위 에이전트, Cornell 우승작의 금액 한도 초과 시 직원 이관, 확신도 표시. 우리 에이전트 팀 + 점장 에스컬레이션이 이 패턴에 해당한다.
7. 이야기와 시각화로 기억에 남는다. "Story > slides", "judges remember narratives more than features", Cornell의 최우수 시각화·발표 별도 시상, Bit2Brain의 그래프 화면. 우리는 신입 알바의 첫날 장면 한 컷 + 그래프가 자라는 화면으로 연다.

보너스 관찰(근거는 약함): 입상작이 해당 연도 학술대회 주제어를 쓰는 경향이 있다(2025 "Agentic AI" 주제와 마음이음). 심사에 비전문가(국민평가단)가 포함되는 대회가 있어 쉬운 한 줄 설명이 필요하다.


## 6. 우리 발표·데모에 적용할 체크리스트

문제 정의 [문제 20점]
- [ ] 첫 슬라이드에 신입 알바 첫날 장면(쿠폰 오류, 품절, 환불, POS)을 사진·일러스트가 아닌 실제 사례 문장으로 제시
- [ ] 문제 통계는 출처와 연도를 같은 줄에 표기(미검증 수치는 쓰지 않거나 "가정"으로 표시)
- [ ] 이용자 3주체(신입, 점장/고참, 고객)별 불편을 한 표로 정리
- [ ] 학회 정체성 연결: 암묵지의 형식지화, 조직 학습, 인간-AI 상호작용(회장 인사말 키워드), 셀프서비스 그림자노동 비판을 피한다는 문장

AI 기술 활용 [AI 20점]
- [ ] "왜 LLM이어야 하는가"를 규칙 기반·FAQ와 비교한 한 문단
- [ ] 에이전트별 단일 책임과 이름(예: 수집, 정리, 응대 코치, 검증)을 구조도에 표기, 확신도 표시
- [ ] 온톨로지 그래프가 응답 품질에 어떻게 기여하는지(근거 경로 표시) 한 예시

창의성·차별성 [창의 20점]
- [ ] 비교표: 일반 매뉴얼/위키/Konveyor류 온보딩 에이전트/우리(매장 예외 처리 + 실시간 그래프 + 점장 에스컬레이션)
- [ ] 모르는 질문이 점장에게 올라가 답이 지식으로 환류되는 루프를 그림 한 장으로

비즈니스 타당성 [비즈 20점]
- [ ] 구매 주체(점주/프랜차이즈 본사)와 지불 구조, 1개 매장 파일럿에서 다점포 확장 경로(서비스경영학회 심사 키워드: 시장성·확장성)
- [ ] 성과지표(KPI)는 목표 가정으로 표시: 신입 교육 시간, 응대 오류율, 점장 호출 횟수

기술 실현 가능성 [기술 20점]
- [ ] 사용 모델, 저장소, 입력 데이터, 비용 추정을 구성도 1장에 정리(NIA 심사평 "구현 가능성"에 대응)
- [ ] 개인정보·민감정보 보호 방안 1장(최소 수집, 가명처리, 고객 정보 LLM 비전송), 제작 과정의 AI 활용 범위 명시(공식 유의사항)
- [ ] 실제 데이터 일부 또는 합성 데이터 구분 표기

데모·발표 형식
- [ ] 60초 라이브 또는 녹화 데모(상황 입력 → 에이전트 응답 → 모를 때 점장 호출 → 그래프 갱신), 오프라인 백업 영상
- [ ] 지도교수명 기재, 본문 PPT 15쪽 내외 구성(배경·문제 / 서비스 / 기술 / 운영·기대효과 / 실현·확장)
- [ ] 비전문가 심사위원도 이해하는 한 줄 설명 준비
- [ ] 후속 확인: 2025 대상팀 조사, Devpost 3-8 항목 사람이 브라우저로 확인
